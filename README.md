# Music Festival Artist Management System
### CSE326 – Internet Programming Project

A beautiful, modern web-based system for festival organizers to manage artists, stages, performance slots, technical requirements, and detect scheduling conflicts.

---

## 🎯 Project Objective
To create an **artist and stage-management system** for music festival organizers.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| **Artist Profiles** | Add, view & delete artists with genre, contact, bio & status |
| **Stage Allocation** | Manage stages with capacity, location and status |
| **Performance Slots** | Book artists on stages with date & time |
| **Technical Requirements** | Track equipment, power needs & special notes |
| **Schedule** | Beautiful timeline view of the entire festival |
| **Conflict Detection** | Automatically finds overlapping performances on the same stage |

---

## 🛠️ Technologies Used
- **HTML5** – Structure
- **CSS3** – Beautiful neon festival theme, animations, responsive design
- **Minimal JavaScript** – Form handling, localStorage, conflict detection logic

## 🚀 How to Run
1. Download / extract the folder
2. Open `index.html` in any modern browser (Chrome, Firefox, Edge)
3. No server or installation needed – pure front-end project

**Note:** Data is saved in the browser’s `localStorage`, so it persists between page refreshes.
